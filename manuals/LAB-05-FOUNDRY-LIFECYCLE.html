PwC Lab 5 - Publish, test, trace, query, evaluate

Extra Foundry lifecycle features for the PwC workshop.

Goal

Use one of your deployed workshop agents to practise the full lifecycle: publish, call by API, inspect traces, query logs, and run evaluations.

Recommended agent: pwc-knowledge-agent.

1. Confirm your project and agent

$env:FOUNDRY_PROJECT_ENDPOINT
az account show --query user.name -o tsv
azd ai agent list

You should be signed in as attendeeNN@MngEnvMCAP063772.onmicrosoft.com.

2. Confirm the pre-deployed agent

  1. The instructor pre-deployed four sample agents into your project.
  2. Use pwc-knowledge-agent for this lab.
  3. If you edit instructions in the portal, save a new version before testing again.

Publishing from source with azd deploy is instructor-led for this locked-down workshop.

3. Call the agent with curl

$TOKEN = az account get-access-token --scope https://ai.azure.com/.default --query accessToken -o tsv
$ENDPOINT = "$env:FOUNDRY_PROJECT_ENDPOINT/agents/pwc-knowledge-agent/responses"
curl.exe -fsS $ENDPOINT `
  -H "Authorization: Bearer $TOKEN" `
  -H "Content-Type: application/json" `
  -d '{"input":"What is the maximum hosted-agent idle timeout?","stream":false}'

4. Inspect traces in Foundry

  1. Open ai.azure.com.
  2. Select proj-attendee-NN.
  3. Open Tracing.
  4. Find your curl request.
  5. Review input/output tokens, tool calls, latency, model name, and correlation ID.

5. Query logs with KQL

Open Log Analytics workspace law-pwc-agents-lab, then run discovery first:

search *
| where TimeGenerated > ago(1d)
| summarize Rows=count() by $table
| order by Rows desc

Then query by your project:

search *
| where TimeGenerated > ago(1d)
| where tostring(*) contains "proj-attendee-NN"
| take 100

6. AI Gateway discussion

This workshop explains gateway patterns, but gateway setup can vary by tenant and product rollout.

  1. Direct agent endpoint: simplest for a lab.
  2. Gateway endpoint: useful for central policy, throttling, keys, and consumer-level reporting.
  3. Ask the instructor before changing gateway or API Management settings.

7. Run an evaluation

  1. In Foundry, open your project.
  2. Open Evaluations.
  3. Create an evaluation for your agent.
  4. Use a small synthetic dataset or examples from your knowledge source.
  5. Review groundedness, relevance, coherence, and individual failed rows.

8. Optimise and compare

  1. Change a prompt or instruction.
  2. Deploy a new version.
  3. Run the same evaluation again.
  4. Compare scores and failures before accepting the change.

Finish

You have now used the extra Foundry lifecycle features that are not covered deeply in the standard AI-103 labs.
