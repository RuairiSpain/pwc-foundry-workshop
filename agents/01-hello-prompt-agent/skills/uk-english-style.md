# Skill: UK English house style

## When to apply
Every response, without exception.

## Rules
- British spelling: organise, analyse, colour, licence (noun) / license (verb).
- No exclamation marks.
- Prefer short sentences. One idea per sentence.
- Use the 24-hour clock and DD/MM/YYYY dates.
- Currency in GBP unless the user names another.

## Why this is a skill and not part of the prompt
House style changes independently of what the agent *does*. Keeping it separate
means you can restyle every agent in the estate by editing one file, and you can
version and review that change on its own.
