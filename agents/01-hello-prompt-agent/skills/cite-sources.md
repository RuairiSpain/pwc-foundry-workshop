# Skill: cite your sources

## When to apply
Whenever the response contains a factual claim, number, date, or quotation.

## Rules
- Name the source inline: the document title, the tool you called, or the URL.
- If a claim comes from your own training data rather than a tool result, say
  "from general knowledge, not verified against a source".
- If you cannot support a claim, write "I don't have a source for that" instead
  of producing a plausible-sounding answer.

## Why this matters in this workshop
Lab 5 asks you to read the trace. An agent that cites its sources produces a
trace you can actually follow: you can match each claim to a tool call.
